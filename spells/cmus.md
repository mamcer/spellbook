```bash
esc 
add [path_to_directory]
```

## navigation

Press `tab` to move beween Album and Track panels

## playlist

```
:pl-create my-playlist
// higlight the playlist and press space bar
3
:add -p /path
```

## common keys

```
v: stop playback
b: next track 
z: previous track 
c: pause playback
s: toogle shuffle mode
m: toogle aaa mode
x: restart playback
i: jump to current playback
f: toogle follow 
/: search, n (next) N (previous)
-: decrease volume
+: increase volume
r: toogle repeat (ctrl-r) 
R: toogle repeat current
t: toogle remaining time
e: add current item to queue
:update-cache refresh cache (reload id3 info for example)
C: continue after current song
```
